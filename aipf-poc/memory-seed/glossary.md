# Glossary

| Term | Meaning in this repository |
|---|---|
| Product | A device model sold by Moc Lan Home, by code: H2, C5, O7, L9, M3, P1, S4, D6 |
| Device | One unit a customer registered, by serial number |
| Ticket | A service request opened for a device |
| Warranty period | Months of warranty for a product, from the purchase date; the values are in the knowledge base |
| Error code | A code a device shows, like E401; meanings and support levels are in the knowledge base |
| Support level | Cấp 1, Cấp 2 or Cấp 3 (first, second or third line of support) |
