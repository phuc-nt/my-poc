# OVR システム概要

- 文書名: 社内備品貸出管理システム 画面仕様書、版 0.9（顧客レビュー用）、発行 サンプル商事株式会社 総務部（架空）
- 注記: PoC 用に作成した架空の仕様書である。実在の企業・システム・人物とは関係ない
- OVR-1 目的: 社内のノートPC、プロジェクター、カメラなどの備品の貸出・返却を、紙の台帳から Web システムに移行する。備品の所在を常に把握できるようにし、返却の遅れを減らす
- OVR-R01 一般社員: 備品を検索し、貸出を申請する
- OVR-R02 承認者: 所属部門の部門長。部門の社員の申請を承認・却下する
- OVR-R03 備品管理者: 総務部の担当者。窓口での貸出・返却の受付と、備品の登録を行う
- OVR-R04 システム管理者: 情報システム部の担当者。ユーザーとお知らせを管理する
- OVR-3 業務の流れ:
  1. 一般社員が備品を検索（SC-03、SC-04）し、貸出を申請（SC-05）
  2. 承認者が申請を承認（SC-07）
  3. 備品管理者が窓口で備品を渡し、貸出を記録（SC-08）
  4. 返却時は、備品管理者が窓口で返却を記録（SC-08）
  5. 返却予定日を過ぎた貸出は、夜間バッチで督促（SC-09）
- OVR-T01 備品: 資産番号で管理する、貸出の対象となる物品
- OVR-T02 備品状態: 「貸出可」「貸出中」「修理中」「廃棄」の4値
- OVR-T03 申請状態: 「申請中」「承認済」「却下」「貸出中」「返却済」の5値
- OVR-T04 貸出期間: 貸出開始日から返却予定日までの期間（両日を含む）
- OVR-T05 督促: 返却予定日を過ぎた貸出について、メールで返却を求めること
- OVR-N01 利用時間: 平日 8:00〜20:00。ただし夜間バッチの実行中は利用できない
- OVR-N02 性能: 画面の応答は高速であること
- OVR-N03 利用者数: 社員約800名
- OVR-N04 対応ブラウザ: Microsoft Edge、Google Chrome の最新版
