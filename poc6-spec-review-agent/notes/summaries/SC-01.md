# SC-01 ログイン

- SC-01-1 概要: 社員がシステムにログインする画面。システムの URL にアクセスしたとき、未ログインであれば本画面を表示する。
- SC-01-2 画面項目: 3項目（SC-01-F01〜F03）の表。
- SC-01-F01 ユーザーID: 必須 ○、桁数 8。備考は「社員番号（半角数字8桁）」。
- SC-01-F02 パスワード: 種類 パスワード、必須 ○、桁数 8〜32。備考は「入力値はマスクして表示する」。
- SC-01-F03 ログイン: 種類 ボタン、必須 -、桁数 -。備考なし。
- SC-01-3 処理: 4処理（SC-01-R01〜R04）の表。
- SC-01-R01 認証: ユーザーIDとパスワードで認証する。失敗した場合は MSG-E003 を表示する。
- SC-01-R02 アカウントロック: パスワードを一定回数連続で誤った場合はアカウントをロックし、MSG-E004 を表示する。
- SC-01-R03 画面遷移: 認証に成功した場合はメニュー（SC-02）へ遷移する。
- SC-01-R04 自動ログアウト: ログイン後、60分間操作がない場合は自動的にログアウトする。
