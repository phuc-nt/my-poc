# SC-02 メニュー

- SC-02-1 概要: ログイン後に最初に表示する画面。お知らせ、利用できる機能へのボタン、自分が借りている備品を表示する。
- SC-02-2 画面項目: 3項目あり（SC-02-F01、SC-02-F02、SC-02-F03）。必須・桁数の指定はなし。
- SC-02-F01 お知らせ: システム管理者が登録したお知らせを、登録日の新しい順に5件表示する。
- SC-02-F02 機能ボタン: CMN-2 の権限で利用可となる画面のボタンだけを表示する。
- SC-02-F03 貸出中の備品: 自分が借りている備品を、返却予定日の近い順に表示する。返却予定日を過ぎたものは赤字で表示する。
- SC-02-3 処理: 2件あり（SC-02-R01、SC-02-R02）。
- SC-02-R01 画面遷移: 機能ボタンを押すと、対応する画面へ遷移する。
- SC-02-R02 貸出中の備品が0件: 「貸出中の備品」に MSG-I001 を表示する。
