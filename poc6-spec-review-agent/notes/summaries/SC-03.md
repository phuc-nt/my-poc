# SC-03 備品検索

- SC-03-1 概要: 貸出を希望する備品を条件で検索する画面。
- SC-03-2 画面項目:
  - SC-03-F01 キーワード: 必須 -、桁数 50。備品名または型番の部分一致。
  - SC-03-F02 カテゴリ: プルダウン、必須 -。「PC」「周辺機器」「映像機器」「その他」。初期値は空欄（全カテゴリ）。
  - SC-03-F03 状態: チェックボックス、必須 -。備品状態（OVR-T02）の4値から選択。初期値は「貸出可」のみ選択。
  - SC-03-F04 検索: ボタン。
  - SC-03-F05 検索結果: 一覧。資産番号、備品名、カテゴリ、状態、保管場所を表示。
- SC-03-3 処理:
  - SC-03-R01 検索: 入力したすべての条件を満たす（AND）備品を検索結果に表示。
  - SC-03-R02 該当なし: 該当する備品がない場合 MSG-I001 を表示。
  - SC-03-R03 ページング: 1ページの表示件数は適宜とする。
  - SC-03-R04 画面遷移: 検索結果の備品名を押すと、備品詳細（SC-04）へ遷移。
