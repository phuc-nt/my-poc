# SC-04 備品詳細

- SC-04-1 概要: 備品の詳細と今後の貸出予定を表示する画面。ここから貸出申請へ進む。
- SC-04-2 画面項目: 表示項目6件（SC-04-F01〜F06）。必須・桁数はいずれも「-」。
- SC-04-F01: 資産番号（表示）
- SC-04-F02: 備品名（表示）
- SC-04-F03: 写真（画像）。写真が登録されている場合のみ表示する
- SC-04-F04: 状態（表示）。備品状態（OVR-T02）
- SC-04-F05: 貸出予定（一覧）。申請状態が「承認済」の申請の貸出期間を、開始日の早い順に表示する
- SC-04-F06: 貸出申請（ボタン）。状態が「貸出可」のときだけ活性にする
- SC-04-3 処理: 処理1件（SC-04-R01）。
- SC-04-R01: 画面遷移。「貸出申請」を押すと、資産番号を引き継いで貸出申請（SC-05）へ遷移する
