# SC-05 貸出申請

- SC-05-1 概要: 一般社員が備品の貸出を申請する画面。申請は所属部門の承認者が承認する。
- SC-05-2 画面項目
  - SC-05-F01 備品: 表示。SC-04 から引き継いだ資産番号と備品名を表示する。
  - SC-05-F02 貸出開始日: 日付、必須、桁数10。YYYY-MM-DD 形式で入力する。
  - SC-05-F03 返却予定日: 日付、必須、桁数10。
  - SC-05-F04 利用目的: テキストエリア、必須。
  - SC-05-F05 申請: ボタン。
- SC-05-3 処理
  - SC-05-R01 期間チェック: 貸出期間は最大14日。14日を超える場合は MSG-E005 を表示する。
  - SC-05-R02 開始日チェック: 貸出開始日は申請日の翌日以降。それより前の場合は MSG-E005 を表示する。
  - SC-05-R03 承認依頼: 申請を登録し、申請者の所属部門の承認者に MAIL-01 を送信する。登録後に MSG-I002 を表示する。
  - SC-05-R04 申請状態: 登録した申請の申請状態は「申請中」とする。
