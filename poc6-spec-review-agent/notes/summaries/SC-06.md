# SC-06 申請一覧

- SC-06-1 概要
  - 自分が行った貸出申請の一覧と状態を確認する画面
- SC-06-2 画面項目
  - SC-06-F01 申請一覧（一覧）
    - 自分の申請を申請日の新しい順に表示する
    - 表示項目: 申請番号、備品名、貸出期間、申請状態（OVR-T03）
  - SC-06-F02 取消（ボタン）
    - 申請状態が「申請中」の行だけ活性にする
- SC-06-3 処理
  - SC-06-R01 取消
    - 「取消」を押すと MSG-C002 を表示する
    - OK の場合は申請を削除する
  - SC-06-R02 申請番号
    - 形式: 「R」＋西暦4桁＋5桁の連番（例: R202600001）
    - 連番は年ごとに1から振り直す
