# SC-07 承認

- SC-07-1 概要: 承認者が、自部門の社員の貸出申請を承認・却下する画面。
- SC-07-2 画面項目:
  - SC-07-F01 承認待ち一覧: 自部門の申請のうち、申請状態が「申請中」のものを申請日の古い順に表示する。
  - SC-07-F02 コメント: 桁数200。却下・差戻しのときは必須。
  - SC-07-F03 承認: ボタン。
  - SC-07-F04 却下: ボタン。
  - SC-07-F05 差戻し: ボタン。申請者に申請内容の修正を求める。
- SC-07-3 処理:
  - SC-07-R01 承認: 申請状態を「承認済」にし、申請者に MAIL-03 を送信する。
  - SC-07-R02 却下: 申請状態を「却下」にし、申請者に MAIL-03 を送信する。
  - SC-07-R03 自動処理: 承認者が一定期間操作しない申請は、自動的に処理する。
