# SC-09 期限超過一覧・督促

- SC-09-1 概要: 返却予定日を過ぎた貸出を一覧で確認し督促メールを送る画面と、督促の夜間バッチ
- SC-09-2 画面項目: 以下2項目
- SC-09-F01 期限超過一覧（一覧）: 申請状態が「貸出中」で返却予定日を過ぎた申請を、超過日数の多い順に表示。表示項目は申請番号、申請者氏名、備品名、返却予定日、超過日数
- SC-09-F02 督促メール再送（ボタン）: 選択した行の申請者に MAIL-02 をすぐに送信
- SC-09-3 処理: 以下3処理
- SC-09-R01 督促バッチの実行: 毎日夜間に実行
- SC-09-R02 督促メール: 期限を超過した貸出の申請者および関係者に MAIL-02 を送信
- SC-09-R03 超過日数: 超過日数 ＝ バッチ実行日 − 返却予定日。土日・祝日も日数に含める
