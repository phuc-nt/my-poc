# SC-10 備品登録・編集

- SC-10-1 概要: 備品管理者が備品を新規登録・編集する画面。
- SC-10-2 画面項目:
  - SC-10-F01 資産番号: 必須 ○、10桁。備考: 半角英数字。登録後は変更できない
  - SC-10-F02 備品名: 必須 ○、50桁
  - SC-10-F03 カテゴリ: プルダウン、必須 ○、桁数 -。備考: SC-03-F02 と同じ選択肢
  - SC-10-F04 状態: プルダウン、必須 ○、桁数 -。備考: 「貸出可」「予約済」「貸出中」「修理中」「廃棄」
  - SC-10-F05 保管場所: 必須 ○、50桁
  - SC-10-F06 写真: ファイル、必須 -、桁数 -。備考: JPEG または PNG、5MB 以下
  - SC-10-F07 登録: ボタン、必須 -、桁数 -。備考: 押下時に MSG-C001 を表示する
- SC-10-3 処理:
  - SC-10-R01 資産番号の重複: 入力した資産番号が既に登録されている場合は MSG-E006 を表示し、登録しない
  - SC-10-R02 廃棄: 状態を「廃棄」にした備品は、備品検索（SC-03）の検索結果に表示しない
  - SC-10-R03 状態の変更: 備品管理者は本画面で状態を手動で変更できる
