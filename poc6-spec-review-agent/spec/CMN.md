# CMN 共通仕様

全画面に共通するルール、権限、メッセージ、メールを定義する。各画面の仕様に記載がない場合は本書に従う。

## CMN-1 画面共通ルール

| ID | 項目 | 内容 |
|---|---|---|
| CMN-R01 | セッション | 最終操作から30分操作がない場合はセッションを破棄し、ログイン画面（SC-01）へ戻す |
| CMN-R02 | 日付 | 画面上の日付は、表示・入力ともに YYYY/MM/DD 形式とする |
| CMN-R03 | 必須項目 | 必須項目は項目名の後ろに「*」を表示する。未入力のまま登録した場合は MSG-E001 を表示する |
| CMN-R04 | 二重送信防止 | 登録・申請などのボタンは、押下後に処理が終わるまで非活性にする |
| CMN-R05 | ヘッダー | 全画面のヘッダーに、ログインユーザーの氏名とログアウトボタンを表示する |

## CMN-2 権限

○は利用可、×は利用不可を表す。1人のユーザーが複数のロールを持つ場合は、いずれかのロールで利用可なら利用できる。

| ID | 画面 | 一般社員 | 承認者 | 備品管理者 | システム管理者 |
|---|---|---|---|---|---|
| CMN-A01 | SC-01〜SC-06 | ○ | ○ | ○ | ○ |
| CMN-A02 | SC-07 承認 | × | ○ | × | × |
| CMN-A03 | SC-08 貸出・返却受付 | × | × | ○ | × |
| CMN-A04 | SC-09 期限超過一覧 | × | × | ○ | ○ |
| CMN-A05 | SC-10 備品登録・編集 | × | × | ○ | × |
| CMN-A06 | SC-11 ユーザー管理 | × | × | × | ○ |
| CMN-A07 | SC-12 CSV出力 | × | × | ○ | ○ |

## CMN-3 メッセージ

| ID | 種別 | 文言 |
|---|---|---|
| MSG-E001 | エラー | 必須項目が入力されていません。 |
| MSG-E002 | エラー | 入力形式が正しくありません。 |
| MSG-E003 | エラー | ユーザーIDまたはパスワードが正しくありません。 |
| MSG-E004 | エラー | アカウントがロックされています。管理者に連絡してください。 |
| MSG-E005 | エラー | 指定の期間では貸出できません。 |
| MSG-E006 | エラー | この資産番号は既に登録されています。 |
| MSG-I001 | 情報 | 該当するデータがありません。 |
| MSG-I002 | 情報 | 申請を受け付けました。 |
| MSG-C001 | 確認 | 登録します。よろしいですか？ |
| MSG-C002 | 確認 | 申請を取り消します。よろしいですか？ |

## CMN-4 メール

| ID | 名称 | 宛先 | 件名 | 本文に含める項目 |
|---|---|---|---|---|
| MAIL-01 | 承認依頼 | 承認者 | 【備品貸出】承認依頼 | 申請番号、申請者氏名、備品名、貸出期間、承認画面のURL |
| MAIL-03 | 承認結果通知 | 申請者 | 【備品貸出】申請結果のお知らせ | 申請番号、備品名、貸出期間、結果（承認／却下）、承認者のコメント |
