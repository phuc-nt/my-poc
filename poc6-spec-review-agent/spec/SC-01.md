# SC-01 ログイン

## SC-01-1 概要

社員がシステムにログインする画面。システムの URL にアクセスしたとき、未ログインであれば本画面を表示する。

## SC-01-2 画面項目

| ID | 項目名 | 種類 | 必須 | 桁数 | 備考 |
|---|---|---|---|---|---|
| SC-01-F01 | ユーザーID | テキスト | ○ | 8 | 社員番号（半角数字8桁） |
| SC-01-F02 | パスワード | パスワード | ○ | 8〜32 | 入力値はマスクして表示する |
| SC-01-F03 | ログイン | ボタン | - | - | |

## SC-01-3 処理

| ID | 処理 | 内容 |
|---|---|---|
| SC-01-R01 | 認証 | ユーザーIDとパスワードで認証する。失敗した場合は MSG-E003 を表示する |
| SC-01-R02 | アカウントロック | パスワードを一定回数連続で誤った場合はアカウントをロックし、MSG-E004 を表示する |
| SC-01-R03 | 画面遷移 | 認証に成功した場合はメニュー（SC-02）へ遷移する |
| SC-01-R04 | 自動ログアウト | ログイン後、60分間操作がない場合は自動的にログアウトする |
