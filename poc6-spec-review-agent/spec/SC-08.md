# SC-08 貸出・返却受付

## SC-08-1 概要

備品管理者が総務部の窓口で、備品の貸出と返却を記録する画面。

## SC-08-2 画面項目

| ID | 項目名 | 種類 | 必須 | 桁数 | 備考 |
|---|---|---|---|---|---|
| SC-08-F01 | 資産番号 | テキスト | ○ | 10 | バーコードリーダーで読み取る。手入力も可 |
| SC-08-F02 | 申請情報 | 表示 | - | - | 資産番号に対応する「承認済」または「貸出中」の申請を表示する |
| SC-08-F03 | 貸出 | ボタン | - | - | 申請状態が「承認済」のとき活性 |
| SC-08-F04 | 返却 | ボタン | - | - | 申請状態が「貸出中」のとき活性 |
| SC-08-F05 | 返却時の状態 | ラジオボタン | ○ | - | 返却時のみ入力する。「正常」「破損」 |

## SC-08-3 処理

| ID | 処理 | 内容 |
|---|---|---|
| SC-08-R01 | 貸出 | 申請状態を「貸出中」に、備品状態を「貸出中」に更新する |
| SC-08-R02 | 貸出期間の変更 | 貸出期間は最大1か月とし、窓口で返却予定日を変更できる |
| SC-08-R03 | 返却 | 申請状態を「返却済」に、備品状態を「貸出可」に更新し、返却日を記録する |
| SC-08-R04 | 破損 | 返却時の状態が「破損」の場合は適切に対応する |
