# SC-09 期限超過一覧・督促

## SC-09-1 概要

返却予定日を過ぎた貸出を一覧で確認し、督促メールを送る画面と、督促の夜間バッチ。

## SC-09-2 画面項目

| ID | 項目名 | 種類 | 必須 | 桁数 | 備考 |
|---|---|---|---|---|---|
| SC-09-F01 | 期限超過一覧 | 一覧 | - | - | 申請状態が「貸出中」で返却予定日を過ぎた申請を、超過日数の多い順に表示する。申請番号、申請者氏名、備品名、返却予定日、超過日数を表示する |
| SC-09-F02 | 督促メール再送 | ボタン | - | - | 選択した行の申請者に MAIL-02 をすぐに送信する |

## SC-09-3 処理

| ID | 処理 | 内容 |
|---|---|---|
| SC-09-R01 | 督促バッチの実行 | 督促バッチは毎日夜間に実行する |
| SC-09-R02 | 督促メール | 督促バッチは、期限を超過した貸出の申請者および関係者に MAIL-02 を送信する |
| SC-09-R03 | 超過日数 | 超過日数 ＝ バッチ実行日 − 返却予定日 とする。土日・祝日も日数に含める |
