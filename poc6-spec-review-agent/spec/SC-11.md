# SC-11 ユーザー管理

## SC-11-1 概要

システムを利用する社員を登録・編集する画面。

## SC-11-2 画面項目

| ID | 項目名 | 種類 | 必須 | 桁数 | 備考 |
|---|---|---|---|---|---|
| SC-11-F01 | ユーザー一覧 | 一覧 | - | - | 社員番号の昇順に表示する |
| SC-11-F02 | 社員番号 | テキスト | ○ | 8 | 半角数字。ログインのユーザーIDになる |
| SC-11-F03 | 氏名 | テキスト | ○ | 40 | |
| SC-11-F04 | メールアドレス | テキスト | ○ | 100 | |
| SC-11-F05 | 所属部門 | プルダウン | ○ | - | |
| SC-11-F06 | ロール | チェックボックス | ○ | - | OVR-2 の4ロールから複数選択できる |
| SC-11-F07 | 有効／無効 | トグル | ○ | - | 初期値は「有効」 |

## SC-11-3 処理

| ID | 処理 | 内容 |
|---|---|---|
| SC-11-R01 | 利用者 | 本画面はシステム管理者と備品管理者が利用する |
| SC-11-R02 | 無効化 | 退職した社員は「無効」にする。無効のユーザーはログインできない |
| SC-11-R03 | 登録 | 「登録」を押すと MSG-C001 を表示し、OK の場合に登録する |
