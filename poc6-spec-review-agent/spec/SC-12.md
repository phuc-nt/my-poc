# SC-12 CSV出力

## SC-12-1 概要

備品の一覧と貸出の履歴を CSV ファイルで出力する画面。

## SC-12-2 画面項目

| ID | 項目名 | 種類 | 必須 | 桁数 | 備考 |
|---|---|---|---|---|---|
| SC-12-F01 | 出力種類 | ラジオボタン | ○ | - | 「備品一覧」「貸出履歴」 |
| SC-12-F02 | 期間 | 日付（開始・終了） | - | - | 「貸出履歴」のときだけ入力できる。貸出開始日で絞り込む |
| SC-12-F03 | 出力 | ボタン | - | - | |

## SC-12-3 処理

| ID | 処理 | 内容 |
|---|---|---|
| SC-12-R01 | 備品一覧CSV | 項目は資産番号（半角英数字8桁）、備品名、カテゴリ、状態、保管場所とする |
| SC-12-R02 | 貸出履歴CSV | 項目は申請番号、社員番号、氏名、備品名、貸出開始日、返却予定日、返却日とする。日付は YYYY/MM/DD 形式 |
| SC-12-R03 | ファイル | ファイル名は「出力種類_YYYYMMDDhhmmss.csv」とする。1行目は項目名とする |
